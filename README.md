# OENGO Driver Application (`oengo-driver`)

> **Courier Dispatch, Real-Time Navigation & Instant ONXC Payout Application**  
> Governed by the OENGO Product Architecture & Logistics Engineering Organizations.

## 1. Domain Ownership
This repository authoritatively owns the **Courier Delivery Logistics Experience**:
- **Capabilities**: Real-time dispatch requests, step-by-step route progress, proof of delivery signatures, instant ONXC earnings and tips.
- **Backend Coupling**: Interacts with `oengo-api` and `oenexa-pay` via strictly documented REST/gRPC endpoints.
